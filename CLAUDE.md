# CLAUDE.md

This file provides guidance to Claude Code (claude.ai/code) when working with code in this repository.

## Repository purpose

This is a **dotfiles repository**, not an application. Each tracked file is a config that lives at a specific system path. There is no build, test, or lint step — changes take effect only after the file is copied (or symlinked) to its destination and the relevant tool is reloaded.

## File → destination mapping

| Tracked file | Destination | Reload |
|---|---|---|
| `zshrc` | `~/.zshrc` | `source ~/.zshrc` or new shell |
| `p10k.zsh` | `~/.p10k.zsh` | sourced by `~/.zshrc` |
| `tmux.conf` | `~/.tmux.conf` | `C-a r` (prefix + r) inside tmux |
| `ghostty.config` | `~/Library/Application Support/com.mitchellh.ghostty/config.ghostty` | `Cmd+Shift+,` in Ghostty |
| `yazi/theme.toml`, `yazi/package.toml` | `~/.config/yazi/` | next yazi launch; run `ya pkg install` after copying `package.toml` |

When editing a config here, the user's live system copy at the destination above is **not** automatically updated. If a change needs to be tested live, the file must be copied to its destination first.

## Cross-file invariants

- **Theme: Catppuccin Mocha everywhere.** Colors are hardcoded in `tmux.conf` (status bar / borders), `p10k.zsh` (prompt segments), and `ghostty.config` (`theme = Catppuccin Mocha`). Changing one tool's palette without the others creates visible drift. The canonical hex values are listed in `README.md` under "Color Reference."
- **Prefix is `C-a`, not `C-b`.** `tmux.conf` rebinds the prefix; any new tmux bindings must assume `C-a`.
- **Zinit is the zsh plugin manager.** New plugins go through `zinit light` / `zinit snippet` in `zshrc`, not `oh-my-zsh` directly (OMZ plugins are pulled in as Zinit snippets).
- **Secrets live in `~/.env`, sourced by `zshrc` line ~42.** Never inline API keys in `zshrc` — add them to `~/.env` (chmod 600, untracked). `~/.env` is intentionally outside this repo.

## Editing `p10k.zsh`

`p10k.zsh` is ~1720 lines and is normally generated by the `p10k configure` wizard. Hand-edits are fine for targeted color/segment tweaks, but running `p10k configure` will overwrite the file — any manual Catppuccin color overrides have to be re-applied after the wizard.

## README is authoritative

`README.md` is the user-facing setup guide and the source of truth for: install commands, keybindings (Ghostty / tmux / fzf), aliases, and the troubleshooting list. When changing behavior in any config, update the matching section in `README.md` in the same commit.
